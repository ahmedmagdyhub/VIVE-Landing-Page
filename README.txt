VIVE Landing Page
=================

Files:
- index.html: page structure and content
- style.css: responsive styling
- script.js: mobile navigation and current year

How to run:
1. Extract the ZIP.
2. Open index.html in your browser.

Before publishing:
- Replace the VIVE text logo in index.html with your real logo image.
- Replace the three sample product names/photos with the actual VIVE products.
- Replace the editorial/sample photos if you have brand photography.
- Add real prices, sizes, delivery and return information if applicable.

The Instagram profile and DM links are already set to @vive_eg.
The page uses Google Fonts and Unsplash-hosted sample photography, so internet access is needed for those assets.
